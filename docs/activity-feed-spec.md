# 动态与随手记

将原笔记区域改名为动态。沿用 `/notes`、原详情链接和 `content/notes`，保留已有正文，避免更名导致旧链接及远程内容失效。

动态页直接显示全部公开动态，按日期倒序，同日新动态按创建时间倒序。每条只显示日期、完整文字和可选图片，不显示标题、摘要或封面式文章布局。原详情页同样不显示标题。正文按普通文本呈现并保留换行。

后台总览和动态页提供随手记。发布类型改为 notes，不再生成或要求标题；支持纯文字、图文、纯图，服务端拒绝空内容。动态编辑器隐藏标题等文章元数据，保留文字、图片、可见性。编辑时保留原日期。日志长文继续独立管理；已有日志不自动迁移。

导航、管理分类、归档和其他列表同步改名。新动态不存标题，旧动态标题不展示。验证公开筛选、无标题呈现、发送类型、换行、图片、移动端、lint 与 build 后提交推送，验收后合并。
