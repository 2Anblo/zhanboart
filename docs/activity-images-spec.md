# 动态多图

一条动态最多 9 张图片。随手记支持多选、追加、粘贴、预览和逐张移除；编辑器支持保留旧图、移除旧图和追加新图。单图内容兼容，纯文字和纯图片仍可发布。

正文下方单图按原比例展示，多图三列网格，点击打开原图。新增 `images` 和 `imageR2Keys` 数组，`image` 继续保留首图以兼容已有内容读取方。

动态图片不设置单张或合计文件大小上限。服务端验证数量、格式和旧图片归属；失败时回收本次上传，保存成功后清理被移除的自有图片，删除动态清理全部自有图片。外部引用不删除。

浏览器按 3 MiB 分块上传原图到已认证的 `/api/admin/activity-uploads`，正文请求只携带签名上传凭据。服务端每两块合成一个 6 MiB R2 multipart part（末块可更小），不压缩图片，避免整批文件触发托管平台的请求体限制。随手记、新建与编辑共用该流程。非 JSON 响应转换为可读错误。

凭据有效期为 24 小时。正常完成和失败时清理临时分块，中断合并时取消 multipart；浏览器关闭或网络中断可能遗留 `.chunks/` 对象，可通过 R2 生命周期规则清理。单次保存最多执行 300 秒，存储服务自身仍有对象和分块数量限制。

验证多图发布、编辑、旧单图、9 张上限、失败回滚、移动端网格及 lint/build。独立分支验收后合并。
