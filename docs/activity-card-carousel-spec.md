# 动态图片卡片轮播

用小型叠放卡片轮播替代图片网格。当前图片居中完整显示，相邻图片缩小、轻微旋转并露出边角。支持点击侧卡、左右按钮、键盘方向键和横向滑动，循环切换，不自动播放。单图保留完整展示且隐藏切换控件。

点击当前图片打开原生 modal dialog，留在当前页面查看大图。弹窗支持前后切换、滑动、Escape 和关闭按钮；打开时锁定页面滚动，关闭恢复滚动和当前图片焦点。原生 dialog 限制焦点在弹窗内。

适配手机、浅色与深色主题，图片始终使用 contain，不裁剪主体；遵循减少动态效果设置。验证单图、双图、多图、弹窗、键盘、触摸、焦点和 lint/build。独立分支验收后合并。
