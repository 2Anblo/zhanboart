# 随手记

在 `/admin` 的总览和日志页直接写一条日志：一个文本框、一张可选图片、发布按钮。支持粘贴图片、预览、更换和移除，支持纯文字或纯图片发布。图片最多 4 MB。

复用现有登录、内容保存和图片上传流程。默认公开，日期采用发布者本地日期，标题取首行前 32 个字符，摘要自动截取；链接使用随机标识，重复文字不会产生链接冲突。完整编辑器继续用于后续修改。

空内容无法发布，发送期间防止重复点击，失败保留文字和图片。保存成功立即加入管理列表，公开网站待现有部署流程完成后更新。切换管理分类保留未发送内容；刷新页面不保留。

验收：文字发布、图文发布、纯图发布、空内容拦截、失败重试、图片移除、移动端布局、lint 和 build。独立分支验收后再合并。
