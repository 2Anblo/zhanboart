# zhanbo.art Art Direction Notes

> 内敛的酷。一个安静的梦。不是模板，不是展示页，而是一个网络上的人留下的私人残响。

这个目录用于沉淀 `zhanbo.art` 的审美方向、素材方法和未来页面灵感。它不是产品需求文档，也不是技术规范，而是帮助后续设计和内容选择保持一致的判断系统。

## 1. 核心气质

网站应该给人的第一反应不是“这个人很会做网页”，而是：

> 我好像进入了一个安静、克制、但很有个人品味的梦。

关键词：

- 内敛
- 私密
- 安静的梦
- 网络残响
- 光线
- 记忆碎片
- 暗处的个人品味

避免：

- 像模板
- 像作品集
- 像 moodboard 收藏夹
- 像粉丝站
- 像设计特效展示

核心规则：

> 所有动效都必须像记忆自己在移动，而不是网页在炫技。

## 2. 灵感使用方法

参考优秀网站时，不直接复制具体效果，而是拆解它背后的品味规则。

每个参考网站都可以用这张表分析：

| 参考对象 | 我喜欢什么 | 背后的规则 | 可以迁移到本站哪里 |
| --- | --- | --- | --- |
| 某个网站 | 滚动时内容横向推进 | 用户像穿过空间，不是浏览列表 | 首页中段的梦境走廊 |
| 某个作品 | 情绪很私人 | 不解释，只留下痕迹 | notes / music / journal |
| 某个页面 | 很克制 | 少量元素承担情绪，不堆砌 | Hero / Footer |

真正要偷学的是：

- 它为什么显得高级
- 它拒绝了什么
- 它的情绪如何推进
- 哪些规则属于自己，哪些只是羡慕

没有被抽象成规则的灵感，暂时不要放进网站。

## 3. 横向梦境段落

喜欢的效果：用户向下滚动时，页面右侧滚动条不像普通页面那样快速向下，但屏幕里的内容在水平行进。

技术名称：

> pinned horizontal scroll

适合本站的表达方式：

> Dream Corridor / 信号走廊

不要做成作品集式横向展示。不要一屏一张图、一屏一个标题，那样会很像 agency 模板。

更适合的方式是：用户像穿过一个人的脑内走廊。内容不是“展示”，而是短暂经过。

可以出现的元素：

- 半透明照片
- 极短句子
- 日期
- 时间戳
- 作品名脚注
- 音乐、电影、小说带来的残响
- 一帧色彩记忆
- 模糊的房间、屏幕、耳机、书页

视觉规则：

- 照片可以只露出局部
- 文字不要解释页面功能
- 元素之间留出安静的距离
- 不要每一屏都居中摆卡片
- 横向移动可以有轻微视差
- 移动端退化成纵向碎片流
- 整站不要都做横向滚动，只在中段出现一次

建议比例：

> 视觉 60%，文字 40%。文字更锋利，照片更像证据。

## 4. 素材现实

目前的问题不是“照片不够好”，而是素材来源更偏网络和文化消费，而不是大量外出拍摄。

这不是缺点。这个网站不应该假装自己是到处生活、到处拍照的人。

真实素材是：

- 日本动漫
- 老电影
- 《Taxi Driver》
- 《The Godfather》
- Frank Ocean
- 各种音乐
- 小说
- 网络上反复观看、聆听、阅读后留下的感受

但这些作品不能直接变成门面。

核心规则：

> 作品只作为地下水，不作为门面。

也就是说，页面不应该只是告诉别人“我喜欢 Frank Ocean / 老电影 / 日本动漫”。更重要的是呈现：

> 这些东西如何改变了我，如何塑造了我的孤独、审美、欲望、房间、夜晚和语言。

## 5. 从作品到个人表达

不要直接堆海报、截图、专辑封面或长引用。它们容易让网站变成收藏夹。

更好的方法是把作品转译成私人残响。

例子：

| 输入 | 不建议 | 更适合 |
| --- | --- | --- |
| Taxi Driver | 放电影海报 | 夜里的城市不是外面，是脑子里没有熄掉的灯 |
| Frank Ocean | 做直白粉丝引用 | 有些歌不是在播放，是替我保管某个夏天 |
| The Godfather | 摆经典剧照 | 家族、沉默、继承、昏暗室内、命运缓慢下沉 |
| 日本动漫 | 做二次元拼贴 | 青春、孤独、雨夜、便利店灯光、城市边缘 |
| 小说 | 长段摘抄 | 房间、天气、身体感、某个短句的余温 |

## 6. 三个内容池

为了持续产生个人素材，可以建立三个池子。

### 输入池

只给自己看。记录看过、听过、读过的东西。

字段可以很简单：

- title
- type: film / anime / music / novel / web / image
- date
- why it stayed
- color
- time
- mood

### 残响池

每个作品只提炼 1 到 3 个词。

例子：

- 雨夜
- 车窗
- 失眠
- 家族
- 海边
- 蓝色
- 沉默
- 夏天
- 房间
- 屏幕光

### 输出池

把残响变成自己的句子、页面片段或视觉素材。

例子：

```ts
{
  type: "text",
  body: "有些歌不是在播放，是替我保管某个夏天。"
}
```

```ts
{
  type: "signal",
  source: "late-night film memory",
  color: "#1d2430",
  label: "02:17 AM"
}
```

```ts
{
  type: "image",
  src: "/images/dream/screen-light-01.jpg",
  caption: "屏幕亮着，房间没有说话。"
}
```

## 7. 可收集素材

即使不常出门，也可以收集适合本站的个人视觉素材。

优先收集：

- 屏幕光照在房间里的照片
- 耳机、书页、桌面、杯子、键盘、窗帘
- 夜里电脑前的局部
- 看电影时房间里的反光
- 播放音乐时的环境
- 低清、模糊、过曝、轻微失败的照片
- 某部作品留下的色彩，而不是直接截图
- 自己写下的一句话

不要追求“漂亮照片”。更重要的是：

> 有你存在过的证据。

## 8. 页面落点

适合落在首页中段，而不是首屏。

首页节奏建议：

1. 首屏保持克制，让人进入。
2. 中段出现一次 Dream Corridor，像突然进入梦的深处。
3. 后面回到 journal / notes / music / archive，让内容接住情绪。

各页面方向：

- 首页：精神空间入口，不做自我介绍。
- Journal：长痕迹，不是文章展示。
- Notes：碎片，不是动态。
- Photos：证据，不是相册。
- Music：记忆触发器，不是歌单展示。
- Archive：记忆地层，不是普通归档。

## 9. 技术落地提醒

如果实现 Dream Corridor：

- 使用 GSAP ScrollTrigger 的 pin + scrub。
- Lenis 滚动需要和 GSAP ticker 同步。
- 段落高度由横向内容宽度决定。
- prefers-reduced-motion 下关闭 pinned 横向滚动，改为静态纵向布局。
- 移动端不要强行复刻桌面横向滚动。
- 图片必须有明确尺寸或 aspect-ratio。
- 首屏文字不能等待 WebGL 或复杂动画加载。
- 这个段落应该配置驱动，优先放入 `src/config.ts`。

可能的数据结构：

```ts
export const dreamCorridor = [
  {
    type: "text",
    body: "有些歌不是在播放，是替我保管某个夏天。",
  },
  {
    type: "signal",
    label: "02:17 AM",
    mood: "screen light",
    color: "#1d2430",
  },
  {
    type: "image",
    src: "/images/dream/screen-light-01.jpg",
    caption: "屏幕亮着，房间没有说话。",
  },
];
```

## 10. 判断标准

新增任何设计、动画、素材前，问这些问题：

1. 它是否让网站更像一个安静的梦？
2. 它是否暴露了一点真实的自己，而不只是展示品味？
3. 它是否避免了模板感？
4. 它是否足够克制？
5. 它是否能从“我喜欢这个作品”推进到“这个作品如何改变了我”？

如果答案不清楚，先不要加。

## 11. 下一步

短期不需要立刻做完整横向长廊。先做一个短片段即可。

建议第一版：

- 6 到 8 个元素
- 2 张自己拍的房间/屏幕/桌面照片
- 3 到 4 句私人残响
- 1 到 2 个色彩或时间信号
- 只在首页中段出现一次

第一版的目标不是震撼，而是确定这个网站的私人语气。
